## The entry

> Twelve yoghurts. No spoon, no dignity, no backup plan. Please collect your dairy-based cry for help below.

106 characters — inside the 200-character gate, single line, no padding.

## How it works

`main.py` (Python standard library only) writes the line to
`$MAKEFUN_OUTPUT_DIR/entry.txt`, the file the house gate and judge read.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
